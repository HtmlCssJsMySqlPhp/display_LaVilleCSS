# 🏙️ La Ville CSS — Apprendre `display` en CSS

> **Méthode pédagogique interactive** pour comprendre les valeurs de la propriété CSS `display` : `block`, `inline` et `inline-block`.

---

## 🇫🇷 Français

### Description

**La Ville CSS** est un outil pédagogique visuel et interactif destiné aux apprenants en développement web.  
Chaque valeur de la propriété `display` est illustrée par une métaphore urbaine : des bâtiments dans une rue. L'élève **construit sa propre ville** en ajoutant des éléments et observe en temps réel comment ils se placent les uns par rapport aux autres.

### La métaphore

| Valeur | Bâtiment | Comportement |
|---|---|---|
| `block` | 🏢 **Immeuble** | Prend toute la largeur de la rue — le suivant commence sur une nouvelle rangée |
| `inline` | 🛖 **Kiosque** | Se glisse dans le flux sans saut de ligne — pas de largeur ni hauteur fixe |
| `inline-block` | 🏪 **Boutique** | S'aligne côte à côte comme inline, mais accepte une largeur et une hauteur précises |

### Fonctionnalités

- **Construction interactive** : ajouter des éléments un par un et voir leur comportement immédiatement
- **Clic sur un bâtiment** : affiche l'explication et la règle CSS correspondante
- **Compteur** : suit le nombre de chaque type d'élément ajouté
- **Bouton "Tout effacer"** : repart de zéro pour recommencer l'expérience

### Comment utiliser

1. Ouvrir le lien dans un navigateur web (Chrome, Firefox, Edge…)
2. Cliquer sur **"+ Immeuble (block)"**, **"+ Kiosque (inline)"** ou **"+ Boutique (inline-block)"**
3. Observer comment chaque bâtiment se place dans la rue
4. Cliquer sur un bâtiment pour lire son explication et sa règle CSS
5. Cliquer sur **"Tout effacer"** pour recommencer

### Ce que l'élève doit retenir

| | Nouvelle ligne ? | width / height ? |
|---|---|---|
| `block` | ✅ Oui | ✅ Oui |
| `inline` | ❌ Non | ❌ Non |
| `inline-block` | ❌ Non | ✅ Oui |

### Public cible

- Élèves en formation développement web
- Apprenants autodidactes en CSS
- Enseignants souhaitant un support de cours visuel et ludique

### Prérequis

Aucun. L'application fonctionne directement dans le navigateur, sans installation.

## 🇬🇧 English

### Description

**The CSS City** is a visual and interactive teaching tool designed for web development learners.  
Each value of the CSS `display` property is illustrated through an urban metaphor: buildings in a street. Students **build their own city** by adding elements and instantly observe how they position themselves relative to each other.

### The metaphor

| Value | Building | Behaviour |
|---|---|---|
| `block` | 🏢 **Apartment block** | Takes up the full street width — the next one starts on a new row |
| `inline` | 🛖 **Kiosk** | Slips into the flow without a line break — no fixed width or height |
| `inline-block` | 🏪 **Shop** | Lines up side by side like inline, but accepts a fixed width and height |

### Features

- **Interactive building** : add elements one by one and instantly see their behaviour
- **Click on a building** : displays the explanation and corresponding CSS rule
- **Counter** : tracks the number of each type of element added
- **"Clear all" button** : start fresh and repeat the experience

### How to use

1. Open the link in any web browser (Chrome, Firefox, Edge…)
2. Click **"+ Immeuble (block)"**, **"+ Kiosque (inline)"** or **"+ Boutique (inline-block)"**
3. Observe how each building places itself in the street
4. Click on a building to read its explanation and CSS rule
5. Click **"Tout effacer"** to start over

### Key takeaway

| | New line? | width / height? |
|---|---|---|
| `block` | ✅ Yes | ✅ Yes |
| `inline` | ❌ No | ❌ No |
| `inline-block` | ❌ No | ✅ Yes |

### Target audience

- Students in web development training
- Self-taught CSS learners
- Teachers looking for a fun and visual classroom support tool

### Requirements

None. The application runs directly in the browser, no installation required.
